# AFTERIMAGE / 잔상

**바이브 코딩 프로젝트입니다.** 디자인 시안부터 3D 공간 구현과 공개 배포까지 진행한 가상의 디지털 아트 전시입니다. OpenAI Codex와 Build Web Apps를 활용해 공간과 인터랙션을 구현했습니다.

**[전시 관람하기](https://tnfh23-web.github.io/afterimage/)** · [기획·제작 과정 보기](https://tnfh23-web.github.io/afterimage/#about)

## 제작 계기

‘풍부한 인터랙션’과 ‘콘텐츠에 맞는 디자인’을 직접 실험해 보고 싶어 시작했습니다. 스크롤·호버·클릭에 페이지 전반이 반응하는 경험에 관심을 갖고, 이를 브라우저 안에서 직접 걸어 다닐 수 있는 3D 전시로 확장했습니다.

관람자가 공간을 이동하며 작품을 발견하고, 조각을 돌려 보고, 회화를 가까이 감상하는 경험을 목표로 삼았습니다. 입장 연출과 소리, 작품 설명, 제작 과정을 소개하는 페이지도 전시의 일부로 구성했습니다.

## 전시 콘셉트

‘잔상’은 눈을 감은 뒤에도 남는 장면에서 출발한 이름입니다. 문과 경계, 정지된 정원, 얼굴 없는 초상, 거꾸로 흐르는 시간, 바다의 흔적, 깨어나기 직전의 순간에 이어, 접힌 빛·고요한 균형·여백의 층·숨의 결까지 열 개의 방에 담았습니다.

각 방에는 서로 다른 조각과 회화를 한 점씩 배치해, 총 스무 점의 작품을 감상할 수 있습니다. 높은 천장의 중앙 채광 홀에서 두 전시 동으로 이어지고, 각 동을 한 바퀴 돌아 홀로 돌아옵니다. 방마다 크기와 천장 높이를 달리하고 꺾이는 복도로 장면을 연결했습니다. 관람자는 자유롭게 이동하거나 전시 지도에서 원하는 공간과 작품을 선택할 수 있습니다. 중앙 홀의 계단을 올라가면 2층 전체를 사용하는 상영관이 있습니다. 금빛 문틀과 빛의 잔상이 이어지는 약 48초의 오리지널 영상 **‘여운의 문’**을 부드러운 음악과 함께 반복 상영합니다. 전시 속 작품과 작가 이름은 모두 가상입니다.

## 작업 방식

1. **전시 기획하기** — 전시 주제, 열 개의 방, 자유 이동 방식, 조각과 회화의 구성을 정했습니다. 로고와 전시 공간을 실제 3D로 구현하는 것도 초기 목표에 포함했습니다.
2. **시안으로 방향 정하기** — Build Web Apps의 `frontend-app-builder` 흐름에 따라 구현 전에 공간과 소개 페이지의 콘셉트를 만들었습니다. 방별 분위기, 색상, 글꼴과 로고 방향을 정리했습니다.
3. **공간과 인터랙션 구현하기** — 이미지 자산을 제작하고 Three.js로 건물·복도·조형물·입체 로고를 구성했습니다. React로 지도, 작품 설명, 관람 안내와 소개 페이지를 연결했습니다.
4. **실제 화면을 보며 개선하기** — 시안과 렌더링의 차이를 확인하고, 드래그와 회전의 감각, 등장 효과, 로딩의 속도감과 성능을 조정했습니다.
5. **브라우저 검증과 배포하기** — 실제 브라우저에서 전시 이동과 작품 감상, 사운드, 소개 페이지, 화면 크기에 따른 동작을 확인한 뒤 GitHub Pages에 공개했습니다.

기획 → 시안 → 구현 → 실제 화면 검증 → 수정의 순서로 진행했습니다.

## 기술 스택

| 기술 | 사용한 부분 |
| --- | --- |
| React 19 | 전시 UI, 지도, 작품 정보와 소개 페이지 |
| Vite 7 | 개발 환경과 프로덕션 빌드 |
| JavaScript / JSX | 화면 구성, 공간 제어와 조형물 생성 코드 |
| Three.js / WebGL | 실제 3D 공간·조각·조명·그림자·반사 구현 |
| CSS / IntersectionObserver / Web Animations API | 반응형 레이아웃, 입장 연출과 스크롤 등장 효과 |
| Web Audio API | 배경음과 발소리·작품 선택 효과음 합성 |
| Canvas 2D / MediaRecorder / VideoTexture | 오리지널 영상·음악 제작, MP4 인코딩과 3D 스크린 재생 |
| SVG / GLB | 벡터 로고와 회전 가능한 입체 로고 |
| Pretendard | 본문과 UI 글꼴 |
| GitHub Actions / GitHub Pages | 자동 빌드와 공개 웹 배포 |

React는 관람에 필요한 UI와 상태를 구성하고, Three.js는 공간과 작품의 실시간 움직임을 담당하도록 역할을 나눴습니다. 소개 페이지의 모션은 브라우저 기본 API로 구현했으며, 사운드는 Web Audio로 직접 합성했습니다.

개발 도구로 **OpenAI Codex, Build Web Apps, ImageGen, Browser, Playwright**를 사용했습니다. Build Web Apps의 `frontend-app-builder`를 중심으로 진행하고, `react-best-practices`와 `frontend-testing-debugging`을 코드 개선과 화면 검증에 활용했습니다.

## 주요 경험

- **전시장 설계:** 긴 천창이 있는 중앙 홀, 두 개의 순환 동선, 아이보리 벽과 밝은 석회석 바닥으로 현대적인 갤러리를 구성했습니다. 목재 루버와 벤치, 올리브 식재, 안내 데스크와 전시실 타이포그래피로 공간에 깊이와 머무는 지점을 더했습니다. 지도는 실제 공간의 크기와 연결 경로를 반영합니다.
- **공간 관람:** 키보드·터치로 열 개의 연결된 방을 이동하고, 드래그로 시선을 조작합니다. 데스크톱은 Space로 점프하며, 모바일은 조이스틱을 조금 밀면 걷고 끝까지 밀면 달리며, 별도의 버튼으로 점프합니다.
- **작품 감상:** 회화를 확대하거나 조각을 직접 회전하고, 자동 회전과 시선 초기화를 사용할 수 있습니다. 조각과 회화에는 각각의 형태와 화면에 맞춘 별도의 설명을 제공합니다.
- **분위기 연출:** 노을·달빛·바다·안개 등 방의 주제에 맞춰 조명의 색, 방향과 부드러움을 달리했습니다. 안으로 서서히 다가오는 입장 화면과 첫 조작부터 시작하는 따뜻한 피아노 계열의 배경음과 또렷한 발소리·효과음으로 전시의 분위기를 구성했습니다.
- **2층 상영관:** 실제 계단과 연결 다리로 올라가는 상영관입니다. 월넛 벽과 계단식 좌석, 대형 스크린을 구성했습니다. 영상 재생·일시정지·탐색·처음부터 보기를 제공하고, 입장할 때 영상을 불러오며 다른 공간이나 안내 화면에서는 재생을 쉽니다.
- **제작 과정 탐색:** 여섯 챕터의 소개 페이지에서 기획과 디자인 과정을 살펴보고, 실제 3D 로고를 조작할 수 있습니다.
- **다양한 관람 환경:** 데스크톱·태블릿·모바일 화면과 키보드 조작, 시스템의 움직임 감소 설정을 고려했습니다.

## AI 활용과 자산 출처

콘셉트 이미지, 회화, 로딩 배경과 재질 이미지에는 ImageGen으로 만든 AI 생성 자산이 포함되어 있습니다. 실제 전시 공간과 조각은 이 프로젝트의 Three.js 기하 코드로 구현했고, 로고는 SVG와 GLB로 제작했습니다. 음악과 효과음은 Web Audio로 합성했습니다. 상영 영상은 Canvas 2D 애니메이션과 직접 합성한 음악을 MediaRecorder로 녹화한 MP4(H.264/AAC)입니다. 외부 영상이나 음원은 사용하지 않았습니다.

이미지 시안과 실제 3D 구현에는 차이가 있으며, 특히 흉상의 세밀한 형태와 천의 주름은 추가 모델링이 필요한 부분입니다. 콘셉트 이미지와 실제 구현 화면은 구분해 표시합니다. 상세 출처와 라이선스는 [ASSET-PROVENANCE.md](ASSET-PROVENANCE.md)에 정리했습니다.
