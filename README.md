# AFTERIMAGE / 잔상

여섯 개의 연결된 방을 자유롭게 걷는 가상의 초현실 아트 전시. React19, Vite7, Three.js. WebGL로 벽/바닥/복도/조각/입구 로고를 실제 geometry로 렌더링합니다. 전시 공간은 실제 3D이며, 입장 전 로딩 연출에는 전용으로 생성한 터널 배경 이미지를 사용합니다.

## 실행
Node.js22.12 이상. `npm install`, `npm run dev`. http://127.0.0.1:4174/
배포용 파일 생성: `npm run build`. dist 폴더를 정적 호스팅에 올릴 수 있습니다.

## 관람
WASD/방향키 이동, Shift 빠르게 걷기, 드래그 시선, E 가까운 작품 선택, 작품 클릭 감상. 왼쪽 이동 패드로 터치 이동, 오른쪽 드래그로 시선. 지도에서 여섯 방 이동 및 모든 작품 감상 가능. 조각 감상 중 화면 드래그/자동 회전/시선 초기화. 회화 클릭 확대. Escape로 안내/지도/작품 설명 닫기. 시스템의 모션 감소 설정 존중. 드래그·회전 관성/감속, 자동 회전의 부드러운 시작·정지 및 시선 초기화. #about에서 개요→과제→아이덴티티→디자인 시스템→관람 흐름→인터랙션의 프로세스 소개. 소리 켜기/끄기, 관람 안내 및 소개에서 음량 조절.

## 파일
src/scene.js: 연결 건물, 조명/반사, 충돌과 관람 제어. src/scene-effects.js: 접촉 음영. src/static-room-batches.js: 건축 메시 렌더링 최적화.
src/sculpture-models.js, sculpture-detail.js, sculptures.js: 여섯 조각의 실제 기하 구조.
src/Gallery.jsx: 렌더링 생명주기.
src/main.jsx: 지도, 안내, 작품 정보와 접근성 대화상자.
src/Introduction.jsx, case-study.css: 전시 프로세스 사례 소개 (#about). src/LogoStudy.jsx: 회전 가능한 실제 GLB 로고.
src/angular-motion.js: 프레임 독립적인 카메라 감속/관성.
src/sound.js, use-sound.js: 사용자가 켜는 Web Audio 음악·효과음과 음량.
public/art: 전용 생성 회화 여섯 점 및 재질 텍스처.
public/logo-original.png: 생성 로고 원본. public/mark.svg: 3D와 함께 쓰는 정밀 벡터 심벌.
design: 구현 전 생성한 여섯 콘셉트, 토큰/콘텐츠, 프롬프트.

## 제작
Build Web Apps의 frontend-app-builder로 먼저 콘셉트 생성; react-best-practices 적용; frontend-testing-debugging으로 실제 브라우저 QA. ImageGen은 원본 시각 자산 제작에, Playwright는 자유 이동 및 정확한 뷰포트 검사에 사용했습니다. 별도 커스텀 디자인 워크플로/디자인 에이전트 사용 없음.

## 기술 범위
실시간 브라우저 전시이며 WebGL/하드웨어 가속이 필요합니다. 실사 스캔 대신 직접 만든 절차적 3D 조형물입니다. 시안과 동일한 조형 완성도는 아직 달성하지 못했습니다. 특히 흉상의 해부학적 형태와 섬세한 천 주름은 별도의 정교한 3D 모델링이 필요합니다. 최신 차이와 검증 기록은 design/FIDELITY-REVISION.md에 있습니다. 데스크톱 반사는 비용 제한을 위해 640x480으로 렌더링하며, 좁은 화면에서는 비활성화합니다. 직접 합성한 앰비언트 배경음과 발소리/작품 선택 소리를 사용하며 외부 API/로그인/결제/분석 추적 없음.

모든 인명과 작품은 가상. Pretendard SIL OFL(폰트 폴더 라이선스), Three.js MIT, React MIT, Vite MIT. Helvetiker typeface has its original license in fonts/LICENSE.txt. 앱 자산은 외부 다운로드가 필요 없는 로컬 파일입니다.

Logo exports: public/logo.svg (all paths, no external font), public/logo.glb (solid emblem and wordmark). Original bitmap: public/logo-original.png. Re-export using node export-logo.mjs. Final fidelity and verification notes are in design/DESIGN.md. Actual installation path: C:\Afterimage. start.cmd launches the app locally.

## 포트폴리오와 자산 출처
회화·시안·재질 이미지에는 AI 생성 자산이 포함되어 있습니다. 생산용 3D 조각은 직접 작성한 기하 코드이며, 평가했던 비상업용 외부 STL은 사용하지 않고 이 소스에 포함하지 않았습니다. 자세한 출처와 표기 예시는 ASSET-PROVENANCE.md를 참고하세요. 포트폴리오에는 AI로 생성한 시각 자산과 코드로 구현한 공간·조형·상호작용의 역할을 구분해 표기할 수 있습니다.

## 소개 페이지 모션
기존 여섯 챕터 레이아웃을 유지하며 제목·본문·이미지·항목에 순차적인 스크롤 등장 효과를 적용했습니다. 화면 밖으로 충분히 지나간 뒤 돌아오면 다시 등장합니다. 입체 로고는 천천히 자동 회전하고 드래그 및 방향키 입력 후 약 1.8초 대기한 뒤 부드럽게 재개합니다. 화면 밖과 비활성 탭에서는 렌더링을 중지하며, 움직임 감소 설정에서는 자동 회전과 등장 효과를 끄고 직접 조작만 유지합니다. 구현: src/use-case-motion.js, src/LogoStudy.jsx. 추가 모션 라이브러리 없이 IntersectionObserver·Web Animations·Three.js를 사용합니다.

## 전시 성능과 첫 입장 최적화
사용하는 회화·재질 11개를 WebP로 제공하며 원본 PNG도 보존했습니다. 제공 자산 전체는 35,311,983바이트에서 5,663,610바이트로 감소했습니다(약 84%). 회화 확대의 1536x1024 / 1024x1536 해상도는 유지하고 재질만 1024px로 줄였습니다. 현재 버전은 여섯 방의 회화·셰이더·GPU 버퍼가 준비된 다음 입장을 열어, 첫 방 전환의 동기 작업을 줄입니다. 실제 단계에 연결된 로딩 화면에서 준비 상태를 보여줍니다. 같은 흉상 형상은 재사용하고 고정된 조각 부품을 재질별로 묶습니다. 이동 중 작품 선택은 상세 삼각형 대신 전체 작품의 경계로 검사하며 벽의 가림 판정은 유지합니다.

데스크톱 렌더링은 약 180만 픽셀, 좁은 화면은 약 95만 픽셀을 상한으로 하고 지속적으로 느린 프레임이 측정되면 3D 해상도를 점진적으로 조절합니다. 글자와 버튼은 영향을 받지 않습니다. FXAA로 가장자리를 보정하고 움직이는 조각의 그림자는 약 8회/초로 갱신합니다. 모양·이동·회전·반사·접촉 음영은 유지하지만 저사양 장치에서는 3D 화면이 조금 부드럽게 보일 수 있습니다. 성능은 장치마다 다르며 고정 60fps를 보장하지 않습니다.

## 방 전환과 로딩 화면 — 2026-10-03
여섯 방의 조명을 고정된 조명 풀로 재사용합니다. 방별 위치·색·밝기는 유지하고 활성 GPU 조명/그림자 수를 일정하게 해 방 이동 시 셰이더 구성이 바뀌지 않도록 했습니다. 하나의 그림자 버퍼를 재사용하고, 병렬 셰이더 준비와 64px 오프스크린 렌더로 조각 버퍼를 입장 전에 초기화합니다. 회화와 재질도 미리 업로드합니다. 바닥 반사는 약 30Hz로 제한하고 방 이동에서는 즉시 갱신하며, 지도·안내·소개·확대 화면 뒤에서는 전시 렌더를 쉽니다. 지도 열기/방 이동으로 성능 측정 창이 계속 초기화되던 문제도 제거했습니다.

로딩은 design/loading-concept.png의 밝은 문틀·회화·바닥 반사 구도를 보존합니다. 시안에서 UI를 제거해 만든 286,234바이트의 전용 WebP 배경과 실제 HTML 글자·진행 표시를 합성합니다. 이 배경의 회화는 분위기 연출용 생성 이미지이며 실제 전시의 여섯 작품과는 구분됩니다. 첫 화면부터 약 8초 동안 같은 속도감으로 안쪽에 다가오며, 준비 완료가 카메라를 급가속하거나 재시작하지 않습니다. 마지막 1.8초 동안 전시 공간이 서서히 드러나고 자동 입장합니다. 이전의 17배 급확대·흰빛 섬광은 제거했습니다. 진행률은 실제 파일/GPU 준비를 표시하고 완료 시 100%와 ‘전시로 들어가는 중’을 보여줍니다. 8초는 의도한 입장 연출 시간이며 실제 준비 시간과는 다릅니다. 준비된 뒤 ‘전시 바로 보기’로 짧게 전환할 수 있습니다. 준비가 더 오래 걸리면 실제 준비를 기다린 뒤 전환합니다. 움직임 감소에서는 전진을 끄고 짧게 연결합니다.

로딩 배경과 글꼴이 먼저 표시된 뒤 3D 초기화를 시작합니다. 건물 생성·텍스처 업로드·셰이더 준비 사이에 브라우저가 그릴 시간을 주고, 셰이더는 실제 후처리와 같은 선형 렌더 타깃에서 종류별로 나누어 준비합니다. 깊이 그림자와 후처리 셰이더도 미리 준비합니다. 로딩 중 전시의 지속 렌더는 쉽니다. 매 프레임 React 상태 갱신 없이 CSS transform으로 전진하므로 준비 작업과 겹치는 비용을 줄였습니다. 같은 PC의 짧은 로컬 측정에서 로딩 중 최대 프레임 간격이 약 1.6초에서 약 67ms로 감소했습니다. 캐시·장치·동시 실행 탭에 따라 달라지는 관측값이며 모든 기기의 고정 프레임 속도를 보장하지 않습니다.

소개페이지 입체 로고 회전 속도는 1.05에서 1.55로 약 48% 높였습니다. 드래그 중 멈춤, 부드러운 재개, 화면 밖 렌더 중단, 움직임 감소는 유지합니다.
