# AFTERIMAGE — 채광 홀과 두 전시 동

전체 건물을 재설계한다. 기존 작품 20점과 관람 UI를 유지하고 실제 공간·문·복도·충돌·지도·입장 위치를 하나의 평면 데이터에서 구성한다.

## 컨셉과 자산

- `new-gallery-hall-concept.png`: 1536×1024, 아이보리 플라스터, 밝은 석회석, 높은 채광 홀, 직사각 천창과 어두운 브론즈 보, 양측 출입구와 월넛 벤치. 전체 화면 3D가 주인공이다.
- `new-gallery-material-concept.png`: 기존 작품을 담은 방의 새 재질 기준. 회화와 조각은 기존 실물을 유지한다.
- `limestone-clean-source.png`: 생성한 순수 재질 원본. 1024px WebP를 바닥에 반복한다. 그라우트는 기하로 구성하고 그림자를 이미지에 구워 넣지 않는다.
- 로고: 기존 SVG·실제 3D 문틀과 TextGeometry를 유지. 컨셉의 새 로고로 교체하지 않는다.

## 건축과 동선

중앙 홀 16×34m, 높이 8m. 천창 6×20m. 서쪽 01–05 / 동쪽 06–10의 순환 동선이 각각 홀로 돌아온다. 방은 16–18m 폭, 16–20m 깊이, 4.8–6.6m 높이로 작품에 맞춰 변주한다. 두 개의 L자 복도에서 다음 장면을 드러낸다. 주 출입구 네 곳은 실제 방의 개구부와 연결된다. 단순한 그림 지도 변경은 완료 기준에 해당하지 않는다.

## UI·색상·글자

벽 #ECE5D8, 천장 #F1ECE3, 석재 #D9D3C8, HUD #302E29. Pretendard 기존 크기·굵기·간격 유지. 화면 위 로고, 메뉴, 바닥 안내는 밝은 공간에서 읽히도록 어둡게 한다. 기존 어두운 소개·설명·안내 모달은 유지한다. 벤치는 어두운 월넛, 작품 받침대는 기존 재질.

허용하는 첫 화면 글자: AFTERIMAGE / 전시 소개 / 전시 지도 / 관람 안내 / LOBBY / 채광 홀 / W A S D 이동 · Space 점프 · 드래그 시선 / 소리 켜짐·꺼짐 / 움직임 켜짐·멈춤. 모바일은 기존 조이스틱 안내·달리기·점프 문구 유지. 입장 전 화면과 로딩은 기존 문구 유지한다. HUD 이외 장식 배지나 카드·카루셀을 추가하지 않는다.

## 상태와 연결

새 첫 입장은 채광 홀. 지도에서 중앙 홀과 10개 방을 실제 평면 비율대로 선택한다. 방 번호와 미리 보기는 10개 작품 방만 대상으로 한다. 소개 여섯 챕터 유지, 새 실제 캡처와 공간 설명을 갱신한다. 조각·회화 상세, 키보드 이동·점프, 모바일 이동·달리기·시선·점프, 소리, 움직임 감소를 유지한다. 렌더/자산 준비에는 홀을 포함하며 조명 풀은 고정한다.

## 의도한 차이와 검증

컨셉 이미지는 공간 방향 참고이며 Three.js 실시간 조명에는 사진 수준의 간접광·구름 디테일을 사용하지 않는다. 실제 문 간격은 평면의 연결 가능한 좌표를 우선하며 시점에 따라 가까운 개구부는 시야 밖일 수 있다. 컨셉의 임의 작품·영문 배치는 재현하지 않고 기존 작품·한국어 UI를 사용한다. 입장 연출 시간과 형식은 유지한다.

컨셉과 실제 1536×1024 화면을 열어 벽·바닥·천창·로고·벤치·HUD 대비를 비교한다. 두 동선의 모든 문과 꺾이는 복도를 실제 입력으로 걷고, 벽 충돌·점프·작품 상세·지도·모바일·소개를 확인한다.

조작 대비 보완: 시선이 검은 작품·벤치로 향할 때도 읽히도록 헤더·푸터의 가장자리에 아이보리 페이드를 적용하고, 모바일 안내 글자에는 얇은 반투명 아이보리 바탕을 사용한다. 3D 화면 중앙의 작품과 공간에는 색상 오버레이를 씌우지 않는다.
