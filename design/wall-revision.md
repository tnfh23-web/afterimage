# AFTERIMAGE — 전시실 벽면과 상영관 접속부 보완

기존 10개 방·20점·중앙 홀·2층과 관람 UI를 유지한다. 작품 아래 잘린 텍스트와 맥락 없는 독립 숫자를 제거한다.

## 공간 방향

밝은 현대 갤러리의 바탕을 유지하면서 빈 벽을 작품 주제의 재질과 얕은 입체 부조로 채운다. 방마다 같은 그림을 복제하거나 많은 식재를 늘리는 대신 문틀·가지·원·궤도·물결·빛·접힘·균형·층·호흡을 다르게 구성한다. 벽면에 밀착된 부조와 길이가 다른 오크 리브, 얕은 석재 패널을 사용하며 문·회화·조각·보행 동선을 비워 둔다.

방의 설명은 투명한 글자 plane을 벽에 직접 붙인 기존 방식에서, 실제 두께가 있는 크림색/짙은 바탕의 안내판으로 바꾼다. 상단 주제색·공간명·한글 제목·영문 제목·작가와 구성 작품을 계층적으로 배치한다. 안내판 속 공간 번호는 의미 있는 제목의 일부로만 유지한다.

로비의 비어 있는 남쪽 벽에는 전시 전용 현대 추상 회화를 대형으로 설치한다. 깊은 청색·따뜻한 석회색·테라코타의 겹을 사용해 밝은 공간에서 중심을 만든다. 외부 유명 작품을 내려받지 않고 ImageGen으로 만든 오리지널 장식 작품임을 자산 문서에 밝힌다.

## 구조와 성능

상영관 출입구는 계단·중간참·상부 연결 통로의 높이와 문 위치를 대조한다. 계단 밑으로 겹치는 불필요한 수직 블록, 교차 난간, 겹치는 면과 잘못된 차폐를 확인하고 실제 오르내림을 검사한다. 벽 장식은 조명과 애니메이션을 추가하지 않고 재질별 정적 geometry batching을 사용한다. 대형 로비 회화는 WebP 한 장만 추가한다.

## 소리와 확인

1층 합성 음악과 영화 음악의 실제 출력 크기를 비교한다. 같은 슬라이더에서 1층은 높이고 영화는 낮춰 중간 체감 음량으로 맞춘다. 발소리·음량 조절·음소거를 유지하며 공간 이동에서 소리가 갑자기 튀지 않게 한다.

브라우저에서 10개 방의 문/작품 가림, 안내판 가독성, 로비 회화, 계단 왕복과 상영관 출입, 좌석과 영상 조작을 확인한다. 데스크톱·태블릿·모바일을 구분하고 실제 화면으로 남긴다. 시안/방향 문서와 런타임 캡처를 혼동하지 않는다.
