# 2F 상영관 — 여운의 문

전시의 끝에서 시선을 쉬게 하는 하나의 상영관. 밝은 1층 갤러리에서 지붕과 벽으로 감싼 실제 U형 계단실과 연결 통로를 따라 올라오면 월넛 루버와 어두운 좌석, 금빛 영상이 펼쳐진다.

## 공간과 화면

- 방향 시안: `design/cinema-concept.png`, 1536×1024.
- 상영관: 동쪽 전시 동 위의 16×26m 공간, 2층 전체를 한 상영관으로 사용한다. 중앙 홀의 천창을 보존한다.
- 네 줄의 계단식 좌석과 중앙 통로. 좌석은 둥근 모서리와 어두운 갈색 패브릭 계열로 구성한다.
- 큰 16:9 스크린, 차콜 벽, 월넛 루버, 낮은 호박빛의 통로 조명.
- 화면 글꼴은 기존 Pretendard, 브랜드·전시 소개·전시 지도·관람 안내를 유지한다. 모든 UI는 실제 HTML이며 영상 프레임에 합성하지 않는다.
- 하단: 2F / 상영관, 여운의 문, 시간과 탐색, 재생·일시정지, 처음부터, 1층으로, 소리 전환.
- 걸어서 입장한 관람자를 위한 ‘좌석에서 보기’를 추가한다. 모바일은 앞줄의 실제 좌석에 앉아 영상을 크게 감상하고, 태블릿·모바일 조작부는 하단 정보와 분리한다.

## 영상과 동작

‘여운의 문’은 빛의 문을 지나 입체 금속 리본이 펼쳐지고 입자의 잔상으로 흩어지는 세 장면의 오리지널 모션 작품이다. Three.js와 Web Audio로 만든 영상·음악을 H.264/AAC MP4로 제작한다. 제작 소스는 `design/film-production`에 보존한다.

영상은 상영관 첫 입장 때만 불러온다. 실제 파일 준비 전에는 같은 작품의 포스터를 유지한다. 다른 공간·지도·소개·안내·비활성 탭에서는 재생을 멈춘다. 수동으로 멈춘 상태는 화면을 닫고 돌아와도 유지한다. 전시 배경음은 낮추고 영상의 음악을 들려준다.

## 의도한 시안과 구현의 차이

시안은 공간의 분위기를 정하는 렌더 이미지다. 실제 영화는 시안의 정지 이미지를 움직인 가짜 재생 화면 대신 별도로 제작한 모션 그래픽이며, 실시간 조명과 좌석의 세밀한 재질은 시안의 사진 같은 표현과 차이가 있다. 기존 입체 브랜드 마크, 소리 제어와 감상 위치 버튼은 관람 기능을 위해 유지한다. 16:9 스크린과 실제 네 줄의 좌석·통로·월넛 벽·호박빛 계단선을 공간의 기준으로 삼는다.

## 영상 재제작

프로젝트 루트에서 `node design/film-production/server.mjs`를 실행하고 `http://127.0.0.1:4181/`의 ‘영상 제작 시작’을 누른다. H.264/AAC MediaRecorder를 지원하는 Chrome 계열 브라우저에서 약 48초 동안 해당 탭을 활성 상태로 유지한다. 완성 영상과 포스터는 `public/media`에 저장된다. 지원하지 않는 브라우저는 WebM을 저장하므로 프로젝트의 MP4를 대체하지 않는다.

벤치와 32개 의자는 그려진 가구 위치에서 앉기·일어나기를 제공한다. 가까이에서 버튼·E·의자 클릭으로 앉으며, 시점은 벤치 1.28m / 상영관 바닥 위 1.25m로 낮아진다. 이동이나 점프 입력은 먼저 일어서게 한다. 이전의 안전한 서 있는 위치로 돌아가므로 의자 충돌 내부에서 이동을 시작하지 않는다.
